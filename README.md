# Proiect Dog API - Managementul Versiunilor și AI

Acesta este proiectul final pentru semestrul curent, axat pe integrarea unui API extern și utilizarea riguroasă a Git/GitHub.

## Caracteristici
- **API utilizat**: Dog CEO (Imagini aleatorii cu câini).
- **Elemente DOM**: Imagine dinamică, tabel de metadate, titluri și buton de control.
- **Tehnologii**: HTML5, CSS3 (Design Dashboard), JavaScript (Async/Await).
- **Monitorizare**: Sistem de logging inclus în consola browser-ului.

## Cum se folosește
1. Deschide `index.html` în browser.
2. Apasă butonul "Încarcă alt cățel" pentru a genera o imagine nouă.
3. Verifică tabelul pentru a vedea rasa detectată și statusul cererii.
4. Apasă F12 pentru a vedea log-urile de monitorizare în consolă.
